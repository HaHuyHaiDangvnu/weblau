# Minigame câu hỏi Streamlit

## Chạy trên máy

```bash
python -m pip install -r requirements.txt
python -m streamlit run khungxuong.py
```

## Đưa lên Streamlit Community Cloud

1. Đẩy toàn bộ dự án lên một GitHub repository.
2. Tạo ứng dụng mới tại Streamlit Community Cloud và chọn repository đó.
3. Đặt **Main file path** là `khungxuong.py`.
4. Giữ `requirements.txt`, `quiz_data.py` và thư mục `assets/` trong repository.

Ảnh chúc mừng mặc định nằm tại `assets/chuc_mung_20_10.png`. Khi hoàn thành,
người chơi cũng có thể tải ảnh riêng lên trong ứng dụng.
